**根因**（昨天 15:19 改代码引入的回归）：

- list 被赋成 undefined → 渲染 t.value.length 崩溃 → main 区域空白

**修复**：
- 备份：src/pages/Articles.vue → Articles.vue.bak_20260813_1345
- 改 1 行：`artRes.data.list` → `artRes.data.data.list`
