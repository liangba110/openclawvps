
## 2026-08-15 01:10 PM2 服务统一迁移（aiecom → ubuntu）
- 问题：ai-ecom-site 跑在 aiecom 用户 PM2，默认 pm2 list 看不到；aiecom PM2 无开机自启（pm2-aiecom.service 之前不存在）
- 解决：
  1. 项目/data 目录 chown ubuntu:aiecom（组共享），保证 ubuntu PM2 可读写 site.db/.next
  2. pm2 delete aiecom 的 ai-ecom-site → ubuntu pm2 start node_modules/.bin/next --interpreter /home/ubuntu/.nvm/versions/node/v22.23.0/bin/node -- start -p 3000 -H 127.0.0.1（⚠️ --interpreter 必须放 -- 前面，放后面报 unknown option）
  3. pm2 save 已含两服务；pm2-ubuntu.service 已 enabled 开机自启；禁用 pm2-aiecom.service
  4. 全部脚本（watchdog.mjs/db-guard.cjs/domestic_intel_notify.sh/toc_guard_notify.sh/schedule-runner-cloud.cjs）node/pm2 路径从 aiecom v22.23.2 改为 ubuntu v22.23.0
  5. aiecom crontab 5个任务整体迁到 ubuntu crontab，aiecom crontab 清空（备份 /tmp/aiecom_crontab.bak_20260815_final）
- 验证：三守护脚本手动跑退出码0、schedule-runner 心跳OK、dump 完整、站点 200
- 教训：pm2 有用户隔离，sudo -u 另一用户 pm2 操作需要该用户 sudo 权限；迁移服务必须连带改脚本路径+crontab+自启，否则守护脚本会操作不存在的进程
