### Nginx 配置要点
```nginx
location = /tools/xiaohongshu { return 301 /tools/xiaohongshu/; }
location ^~ /tools/xiaohongshu/ {
    alias /var/www/ai.openai2000.cn/tools/xiaohongshu/;
    index index.html;
    try_files $uri $uri/index.html $uri/ =404;
}
```
- `/tools/` 路径不拦截，走 Next.js 代理（原有工具页面不变）
- 只拦截 `/tools/xiaohongshu/` 子路径

### 踩坑记录
- **dist 目录被清空**：构建脚本 `cp -r public .next/standalone/public` 可能覆盖 `/var/www/` 下的静态目录 → 静态工具文件不要放在会被构建脚本影响的路径
- **alias vs rewrite+root**：`rewrite` + `root` 组合处理子目录时 `try_files` 有坑（目录路径双斜杠问题）→ 用 `alias` 更可靠
- **Vue SPA 子目录部署**：必须加 `<base href="子目录路径/">` 标签，否则 Vue Router 默认用 `/` 导致路由全错
