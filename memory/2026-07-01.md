## 关键技术点 & 坑

1. **后端响应结构**：管理后台用`{code, data, msg}`包装，管理后台dashboard/admin.py和statistics.py都有，前端用`api.get`后默认拿res.data，错了要.data再取
2. **SQL格式化符**：直接`cat > file`写入不会双重转义，但用f-string就要`%%m`
3. **attendance表**：去重需要DELETE t1 FROM t1 INNER JOIN t2，user_id不重复
4. **uploads路径**：Nginx `location /uploads/ { alias /var/www/uploads/ }`
5. **SPA Hash 路由**：所有path都返回index.html（200）
6. **FormData上传**：必须用`api.post('/xxx', formData)`，不能设headers['Content-Type']，浏览器会自动加boundary
