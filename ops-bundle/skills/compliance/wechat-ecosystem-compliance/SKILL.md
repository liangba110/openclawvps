# 微信生态合规（公众号 / 内容站 / 导流）

> 2026-08 实测：同途资讯站（info.openai2000.cn）+ 国际站（www.ttdazi.xyz）合规改造全流程沉淀。

## 触发场景
- 公众号菜单配置 / 调整 / 改名
- 微信内页面跳转、导流到其他网站
- 资讯站 / 内容站 / 落地页合规设计
- 品牌词 / 分类词替换（规避微信敏感检测）
- 给已有平台做英文版 / 展示版

## 一、公众号菜单规则
1. **view 类型菜单 URL 必须是已备案域名**（子域名同主体直接可用，无需重新备案）
2. `menu/create` 直接生效；**publish 报 40066 是旧版机制正常现象，勿用**
3. ⚠️ **菜单不要放"首页 / landing / 平台入口"强推项**——用户明确"不要强推，这样容易违规"。菜单只留内容入口 + 原有功能（验证码 / 公告等），平台导流一律走页面内软性入口
4. 一级菜单有 sub_button 时点击只展开不跳转；只剩一个二级项时，直接做成一级 view 菜单更干净
5. 菜单项改名会牵动品牌一致性：改名后落地页品牌与菜单名不一致时提前告知用户

## 二、微信内导流规则（核心红线）
1. **跳境外未备案域名必触发微信风控 / 拦截** → 一律**零跳转**：只展示完整域名 + "复制链接"按钮 + toast"已复制，请在浏览器打开"
2. **不要用短链接 / 口令 / 二维码包装跳转**——"绕过检测"手段恰是微信打击重点，直接展示完整域名最清白
3. **导流目标以"第三方网站 / 相关推荐"口径出现，与本站撇清关系**（用户明确要求"就当跟我们没关系"）：
   - 按钮文案："更多旅游内容，欢迎访问相关网站"（不写"我们的国际站 / 官方平台"）
   - 免责声明条目："本站与任何第三方网站均无关联，不为其内容及服务负责"
4. **控制导流强度**：不弹窗、不置顶、不每篇硬导；页脚固定软性入口即可
5. 禁止一切诱导元素：❌ 分享后查看 ❌ 关注后解锁 ❌ 点击领奖再跳转

## 三、境外站 / 国际站声明
- 未备案境外站**必须加页脚声明**："本网站仅面向海外用户提供服务"（英文站对应 "This website is intended for overseas users only"），详情页 / About 页也放
- 境外站与境内备案主站保持身份独立；面向境内用户的核心功能（支付/实名）不放在境外站

## 四、敏感词规避（微信检测语境 + 法规低风险）
| 类别 | 词 | 处理 |
|------|----|------|
| 服务提供嫌疑（禁） | 地陪、导游、讲解、向导、结伴、带队、领队、教练 | 替换为纯活动/兴趣词 |
| 社交/婚恋联想 | 搭子 | 替换为**旅伴**（Travel Mate） |
| 社交联想 | 单身经济 | 慎用（婚恋联想），用纯旅游分类替代 |
| 游戏残留（数据过滤） | 带飞、打野、刚枪、狙击、软辅、中路、段位、王者、钻石、御姐、奶音、陪玩、语音陪玩 | 展示层一律过滤 |
| 时政/新闻 | — | 不做时政新闻（需互联网新闻信息服务许可）；政策类内容标注"以官方发布为准" |

- 内容分类用纯旅游词：**旅行攻略 / 目的地推荐 / 政策资讯 / 生活方式**
- 转载注明来源；免责声明齐备（内容仅供参考、不构成服务建议、不提供/撮合/代理任何服务）

## 五、内容站合规架构（免资质模式）
- 纯内容展示：**无交易、无注册认证、无支付** → 无需经营性 ICP / 文网文 / 个保法义务（不收集个人信息 → 无数据出境问题）
- 备案域名 + 纯静态站（HTML+CSS+JS，无数据库无后端）→ 零安全风险、零运维负担、微信内零风控
- 结构参考：首页（banner+分类+列表+达人风采+目的地推荐）→ 列表 → 详情 → 关于（免责声明）；移动端优先
- 公众号菜单 = 备案域名内容站入口，实现"内容价值 → 软性导流"闭环

## 六、从平台 API 生成合规英文版 / 展示站（数据快照模式）
需求"XX平台的英文版"时，先确认是**同款界面+真实内容展示版**（推荐，独立部署零影响）还是完整功能 i18n（需源码+后端，工程大且可能动主平台）：
1. `curl 平台API`（如 `/api/game/list`、`/api/companion/list`）拉真实数据
2. python 处理：**过滤违规词黑名单**（游戏残留+服务嫌疑词：向导/讲解/领队/教练/陪玩/御姐/奶音/段位/王者等）→ 只保留干净昵称
3. 分类名翻译英文（History & Culture、Food Guide、Camping…）；城市翻译（杭州→Hangzhou）；昵称保留原文但过滤
4. tags / rank_title 含游戏残留时**一律不展示**，只展示 昵称/城市/分类/评分/好评率/订单数/参考价
5. 头像用平台真实相对路径（同域 `/avatars/xxx.jpg`，可直接引用）
6. 部署为独立子路径（`location /en/ { alias ...; }` + `location = /en { return 301 /en/; }`），**零影响主站**
7. 英文站自带"overseas users only"声明 + 免责（free / no registration / reference only）

生成脚本见 📖 `scripts/generate_mate_site.py`（含过滤黑名单、分类/城市翻译映射，改路径直接跑）。

## 用户偏好（运营者）
- 合规零容忍：要求"**完全规避微信敏感检测**和**法律法规低风险**"，方案先确认再执行
- 导流必须软性、撇清第三方关系，**绝不强推**
- 品牌词/界面改动先确认范围（"不要动主平台"时只做独立副本）
- 视觉：紫色渐变（#667EEA→#764BA2）同款品牌风，卡片圆角、移动端优先
