## 已部署的安全措施

### WAF (ModSecurity)
- 文件: `/etc/nginx/modsecurity.conf`
- 规则: SQL注入/XSS/路径遍历/命令注入/扫描器/User-Agent拦截
- ⚠️ 调试验证码时临时关闭 (`modsecurity off`)，运营时必须打开

### Nginx 限流
- login_limit: 10r/m (登录接口)
- api_limit: 30r/s (普通API)
- burst 调试: 自动化测试先用 `burst=100` 跑通，再调回生产值

### IP 白名单（管理后台）
```
allow 42.193.113.230;  # 服务器A
allow 127.0.0.1;        # 本机
allow 223.80.95.204;    # 用户IP
deny all;
```

### 登录防护
- 验证码强制（所有登录路径）
- 5次密码错误 → 锁定 15 分钟
- 密码强度: ≥16位 + 大小写 + 数字 + 特殊符号
- 90天密码过期（管理员强制）

### JWT 安全
- 24小时过期（原72小时）
- 封禁账号立即踢下线 (login_required 检查 status=1)
- axios 401 拦截器自动 refresh token + 重试

## 紧急排错

| 症状 | 快速诊断 |
|------|---------|
| Nginx 504 | `ss -tlnp\|grep :5002` 检查后端 |
| Nginx 503 | 看 limit_req / modsecurity |
| 后端 502 | `sudo journalctl -u ttdazi -n 50` |
| 验证码空响应 | 临时关 modsecurity → `/api/captcha/*` 排除 |
| 登录 401 | 检查 refresh_token 字段名 `refresh_token` |
| 验证码 错 | 用户首条用 admin 测，OCR 不靠谱 |
