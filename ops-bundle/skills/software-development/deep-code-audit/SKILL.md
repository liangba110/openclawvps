# 深度代码审计（1M 上下文专用）

## 适用场景
- 整个代码库一次性读取分析
- 跨文件依赖追踪
- 安全漏洞全库扫描
- 架构合理性评估
- 性能瓶颈定位

## 流程
1. `find . -name "*.py" -o -name "*.ts" -o -name "*.js" | head -50` 列出文件
2. `cat` 批量读取（1M 上下文可容纳整个中小型项目）
3. 分析：安全/性能/架构/依赖/重复代码
4. 输出：问题清单 + 修复建议 + 优先级

## MiMo 特性利用
- **1M 上下文**：一次读完整个代码库，不用分次
- **深度思考**：reasoning_effort=high，复杂推理更准确
- **缓存命中**：重复分析相同代码库时，前缀自动缓存（¥0.025/百万token）
- **近千轮工具调用**：大项目可逐文件深度检查

## 审计维度
1. **安全**：SQL注入、XSS、密钥硬编码、权限校验缺失
2. **性能**：N+1 查询、缓存缺失、内存泄漏、慢查询
3. **架构**：职责混乱、循环依赖、过度耦合
4. **代码质量**：重复代码、魔法数字、命名不规范
5. **合规**：敏感信息泄露、日志记录不足
