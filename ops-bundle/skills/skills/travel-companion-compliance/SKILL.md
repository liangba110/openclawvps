# 旅游搭子合规规范

## 一、平台定位

**旅游信息撮合平台**，不提供陪玩服务，不控制服务者。

- 平台禁止代收服务费（仅收信息匹配服务费 ¥10/次）
- 不派单、不调度
- 向导为独立个人，非平台员工

## 二、实名认证准入

1. 双向实名：游客、向导都必须身份证实名
2. 禁止未成年人注册
3. 向导资料人工审核：头像、相册、描述审核

## 十一、公众号资讯/内容站合规（同途资讯模式，2026-08 实测）

在品牌下做**纯内容展示站**（无交易、无注册认证）时合规风险最低，但**微信敏感检测要单独规避**：

1. **纯内容站 = 低风险**：无交易 → 不需要经营性 ICP / 无文网文风险；无注册 → 不收集个人信息、无数据出境义务。必备：免责声明（"内容仅供参考，不构成任何服务建议"）+ 政策类内容标注"以官方发布为准"
2. **微信对婚恋/交友联想词极敏感**：单身、搭子、交友、婚恋、陪伴、向导、地陪、结伴、带队都在检测边缘。站名/内容分类全部用纯内容词：旅行攻略、目的地推荐、政策资讯、生活方式。达人风采照片墙可以保留，但达人简介禁用向导/领路等字眼，用"风景分享达人"
3. **"地陪"术语风险**：涉嫌无资质经营旅游服务，必须换词。"单身经济"本身合法（央媒在报道），但**不能以它为包装做异性社交/陪伴撮合**——只做趋势解读、攻略、目的地内容
4. **导流到境外未备案域名（国际站）必须零跳转**：微信内直接链未备案境外域名必触发风控。做法：固定底部导流条 + 「复制链接」按钮（navigator.clipboard + execCommand 降级）+ toast「已复制，请打开浏览器访问」，页面不放任何直接外链。**目标站自身合规缓解**：境外未备案站页脚加声明「本网站仅面向海外用户提供服务」——注意监管看实质不看形式，声明只能缓解风险，未备案面向境内服务本身仍不合规，最稳路径是目标站明确仅服务海外（境内用户走备案主站）
4.5. **品牌词替换（2026-08-05 用户确认，铁律）**：「搭子」本身不违规，但触发微信社交/交友联想（尤其"旅游搭子"）→ 替换为纯旅游属性词「**旅伴**」。实施：国际站 www.ttdazi.xyz 已全量「搭子→旅伴」（dist 改文案 + immutable 缓存处理见 linux-server-ops 陷阱节），公众号菜单同步改「同途旅伴」；**国内主站 dazi.openai2000.cn 暂保持「同途搭子」未动**（前端/后端/支付备注/协议全未改，用户 2026-08-05 明确要求）——菜单名与落地页品牌短期不一致属用户接受的过渡状态
4.6. **微信外链导流违规 4 层规避**：①架构层——微信内只出现备案域名、境外站零直跳；②内容层——与目标站身份独立、文案中性（"相关推荐"）；③行为层——控制导流强度（不弹窗/不置顶/不每篇硬导）、禁止一切诱导元素（分享后查看/关注后解锁/点击领奖）；④应急——被限制立即停导流+申诉。❌ 不用短链/口令/二维码包装外链（绕过检测的手段恰是微信打击重点），直接展示完整域名最清白
5. **不做时政/突发新闻**（需互联网新闻信息服务许可），政策资讯只引用官方来源
6. **关联站必须"第三方口径"（用户明确要求 2026-08-05，铁律）**：导流的关联站（如 www.ttdazi.xyz）在内容站上**一律不得暴露关联关系**——❌ 严禁"我们的国际站""上同途搭子国际站"等文案；✅ 标准话术：底部条"更多旅游内容，欢迎访问相关网站"；关于页"以下为第三方网站，与本站无任何关联，请自行判断访问"；免责声明必须含"本站与任何第三方网站均无关联，不为其内容及服务负责"。达人卡片点击同样走复制链接，不做站内跳转
7. **公众号菜单不放国际站/落地页强推入口（用户 2026-08-05 明确纠正，铁律）**：菜单里放目标站入口（如"旅伴首页"→landing 落地页）= 官方诱导导流，用户要求"不要强推，这样容易违规"直接删除。菜单只保留：备案内容站（view 类型直达）+ 原有功能项（验证码/公告）。导流只存在于内容站页面内的软性复制链接，**公众号菜单层面零导流痕迹**

## 十二、资质与收款边界（2026-08-05 用户追问定论，铁律认知）

**平台做任何收费业务前必须对齐这套判断，别让用户误以为\"换个名目/换个账户\"能绕开**：

1. **ICP 备案 ≠ ICP 证**：备案（非经营性，免费，所有网站必须）已有；**ICP 证（经营性）只有收费才需要**，个体户办不了 → 收费业务的正路是**升级有限公司**再办 ICP 证（+EDI 证做交易）
2. **\"信息服务费\"仍属经营性**：经营性认定的标准是**是否收费**（向任何一方），不是收什么费。达人展示费/信息服务费/交易佣金在 ICP 证问题上无区别——58同城/BOSS直聘收的也是信息服务费，全有 ICP 证。**唯一免 ICP 证 = 完全免费（纯展示）**
3. **\"私下收费\"= 最差选项（三罪叠加）**：无证经营 + 逃税（不入账）+ 放任线下交易（平台撮合+线下结算 = 刑法上的\"明知放任\"，出事担责更重）。不是第四条路
4. **国际站（境外服务器）确实不在 ICP 证管辖**：ICP 管\"境内经营性服务\"，境外服务器+仅服务海外用户+境内不经营 → 不需要 ICP 证。但收款是独立问题：
   - Stripe/PayPal：中国个体户接不了，需**海外主体**（香港公司最简，成本几千/年）
   - **WorldFirst 万里汇**（蚂蚁旗下）：中国个体户可入驻，合规收外汇结汇到国内卡，无需海外公司
   - **支付宝全球**：中国支付宝商户号（个体户可申请）手机网站支付/当面付——海外用户有支付宝账号（国际版，全球 12 亿）可扫码/跳转付款，人民币结算国内清算，**最简起步路径**（无需新资质）
5. **\"面向境内经营\"认定靠行为不靠声明**：主动引流国内用户去国际站付款 = 自证面向境内经营 = 落入 ICP 管辖。做实\"仅海外\"的三件套：不向境内推广 + 页面全英文声明 + （可选加固）境内 IP 访问显示提示页
6. **两条业务线各归其位**：国内用户（微信生态）→ 备案主站（微信支付+支付宝）；海外用户 → 国际站（境外收款渠道），**互不引流、互不污染**
7. **微信支付\"联系商家\"展示配置**（防骚扰）：商户平台（pay.weixin.qq.com）→ 账户中心/产品中心 → 联系商家/支付凭证设置 → **取消勾选客服电话、保留公众号**——支付凭证的\"联系商家\"只显示公众号入口，电话零展示。公众号资料页客服电话是选填项，不填即不展示。**商户平台后台的联系/验证手机号不能删**（风控必需）；支付凭证的客服电话也别全删（微信要求商户保持可联系，删了投诉率升高会被处罚）
