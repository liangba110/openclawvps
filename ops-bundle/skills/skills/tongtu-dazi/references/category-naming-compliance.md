# 分类命名合规 — 避免旅游资质嫌疑

## 背景

平台定位为「信息中介服务平台」，展示的搭子服务不能具有「旅游经营」性质，否则需要《旅行社业务经营许可证》等资质。

## 命名规则

分类名称必须满足：

1. **不能暗示提供旅游服务**（景点讲解、行程规划、包车向导等 ❌）
2. **不能出现「结伴」字样**（经用户确认，结伴也被排除 ❌）
3. **应该是兴趣/活动/交流类描述**（历史文化、出行攻略、美食向导等 ✅）

## 修改方式

只需更新数据库 `game` 表的 `name` 字段，所有端（首页、搭子列表、需求大厅、搭子端、后台）自动生效，因为全部使用 `/api/game/list` 动态读取。

```sql
UPDATE game SET name='出行攻略' WHERE id=9;
```
