# 合规模式改造（2026-07-14）

## 背景
平台从「游戏陪玩」模式改造为「电竞信息咨询与游戏技术交流对接信息中介服务平台」，规避网络文化经营许可红线。

## 核心变更

### 1. 业务定位（对外口径）
- **不叫**「游戏陪玩平台」
- **标准定位**：电竞信息咨询、游戏技术交流对接中介服务、组队搭档对接

### 2. 术语替换清单
| 旧文案 | 新文案 | 涉及文件 |
|--------|--------|---------|
| 陪玩师 | 游戏搭档 | 全部 26 个 Vue 文件 |
| 陪玩平台 | 游戏技术交流平台 | Agreement.vue |
| 充值中心 | 信息服务 | Profile.vue, Recharge.vue |
| 立即预约 | 立即对接 | Detail.vue, CreateOrder.vue |
| 同途搭子-充值 | 同途搭子-信息匹配服务 | pay_api.py |

### 3. 交易模式改造
**旧模式（高风险）：** 用户付款→资金进平台→选择时长(1h/2h/包夜)→平台结算给陪玩师
**新模式（合规中介）：** 用户支付信息匹配服务费→获取联系方式→双方自行沟通→平台仅赚中介费

### 4. 用户协议 4 文件
`Agreement.vue` 根据 `:type` 参数渲染不同内容：
- `user` — 用户服务协议：明确「信息中介服务平台」
- `privacy` — 隐私政策：信息仅用于撮合服务
- `rules` — 平台规则：禁止情感陪伴/色情/代练
- `disclaimer` — 免责声明：平台不承担服务纠纷

### 5. CreateOrder.vue 重构
- **移除**：选择时长(1h/2h/包夜)、服务时间(立即/预约)
- **新增**：信息对接说明（三条规则）
- **固定金额**：信息匹配服务费 ¥10
- **流程**：展示搭档信息 → 支付 ¥10 → 获取联系方式

### 6. 合规技能
另见 `game-platform-compliance` 技能（合规规范检查清单）。
