# 合规用词映射表

全站系统性替换记录（2026-07-16 执行）。

## 核心替换规则

| 旧 | 新 | 涉及范围 |
|----|----|---------|
| 游戏搭子 | → **搭子** | 用户端页面标题、描述 |
| 游戏技术指导 | → **信息对接** | 详情页、注册页描述 |
| 陪玩师 | → **搭子** | FAQ、后端注释 |
| 包夜 | → **长时间 / 3小时+** | 订单页、资料编辑、FAQ |
| 接单 | → **对接** | 搭子端所有页面 |
| 定价 | → **参考价格** | 注册页、资料编辑 |
| 认证/激活（搭子付费） | → **展示/开通** | 搭子首页、详情页 |
| 续费 | → **续期** | 搭子首页、详情页 |
| 认证费 | → **展示服务费** | 订单创建页、微信支付备注 |
| 认证费用说明 | → **达人认证费用** | 订单创建页 |
| 游戏陪玩服务 | → **信息匹配服务** | systemd 服务描述 |
| 对接 | → **信息对接** | 详情页统计标签 |
