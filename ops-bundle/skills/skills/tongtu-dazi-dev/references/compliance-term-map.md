## 批量替换方法

用 Python replace 批量覆盖 `.vue` 文件：

```python
replacements = {
    '"游戏搭子"' : '"搭子"',
    "'游戏搭子'" : "'搭子'",
    '游戏技术指导': '信息对接',
    '接单': '对接',
    # ... 完整映射见上表
}
```

注意：`"包夜"` 在 SQL 数据库备份和 `price_night` 字段名中保留（历史数据），只替换前端文案。

## 关键合规原则

1. **不承诺服务**：所有价格标注「参考价格」，不显示为服务定价
2. **不出现包夜**：该词是合规红线（暗示过夜陪伴），替换为「长时间」
3. **平台定位**：信息中介撮合平台，非服务提供方
4. **收费名目**：一律叫「信息匹配服务费」，非娱乐服务费
5. **后端代码注释/document string**：可保留原始术语（不影响用户可见），但FAQ数据必须替换

## 常见遗漏点

- `CompanionRegister.vue` 标题「成为搭子」
- `PlaymateLogin.vue` 标题「搭子登录」
- `Favorites.vue` 空状态文案
- `Home.vue` 搜索占位文案
- `Agreement.vue` 协议正文
- `VerifyIdentity.vue` 认证说明
- 后端 `faq.py` 的 FAQ 数据（类别名、关键词、回复内容）
- systemd 服务描述
- 管理后台 admin 页面的「包夜/定价」表格头
