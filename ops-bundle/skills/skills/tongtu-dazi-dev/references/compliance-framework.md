# 平台合规框架

## 业务重新定位

对外统一口径：**电竞信息咨询、游戏技术交流对接中介服务**
禁止高频词汇：陪玩、声优、陪聊、娱乐陪伴、开黑服务
替换用词：游戏技术指导、组队搭档对接、电竞同行匹配、战术咨询

## 交易模式改造

### ❌ 禁止模式（高危）
用户付款→资金进入平台账户→平台结算给陪玩师
平台作为服务销售方售卖时长 → 监管视角：经营线上娱乐服务 → 需文网文

### ✅ 推荐模式（中介信息撮合）
1. 平台只展示供需信息，不直接售卖时长服务
2. 收费名目改为：**信息匹配服务费 / 咨询对接服务费**
   → 逻辑：赚的是中介信息服务费，不是售卖游戏陪伴服务
3. 用户协议写明：平台仅提供信息展示、撮合对接，不直接提供任何线上游戏陪伴服务

## 经营范围标准化

优先登记（不需要前置许可）：
- 信息技术咨询服务
- 电竞信息咨询
- 组织文化艺术交流活动（不含演出）
- 互联网销售（除需要许可的商品）
- 信息咨询服务
- 市场营销策划
- 软件开发

❌ 不要主动添加：网络文化经营、互联网文化活动

## 功能红线（一旦触碰，规避失效）

### 绝对不要做
1. **不自建语音聊天室、实时音视频房间、连麦功能**
   → 撮合成功后双方用第三方软件（微信语音、游戏内置语音）沟通
2. **严禁虚拟币、充值、礼物打赏、会员畅玩时长包**
3. **禁止情感陪伴、哄睡、声优聊天等非游戏技术类服务**
4. **禁止游戏代练、账号交易**

## 支付合规处理

1. 收款商品名不能用：陪玩、开黑时长、娱乐服务
   → 统一设置：**电竞信息匹配服务费、技术咨询对接服务费**
2. 用户协议清晰公示平台仅提供信息中介
3. 建议只收中介费，不全额代收陪玩服务费

## 必备基础资质
1. 营业执照（个体户起步可行）
2. 域名 ICP 备案
3. 公安联网备案
4. 网站公示隐私政策、用户服务协议
